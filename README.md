# SolarFlare
This was a group project for a college class. 
It is just 2048 but with a cool color scheme.

## Tech stack
* AngularJS frontend
* ExpressJS backend
* MySQL database


## REST API
We did a frontend and backend that talk with a REST API.
No, it is not needed for this project we just did it cuz free will.

## Deployment
This project was deployed, but it is no longer active. I deployed it on my own machine, using CloudFlare Tunnels to make it accessible to the public
Everything was deployed in docker containers. The dockerfiles, docker compose yaml, and nginx config files are on the docker banch of this project.
